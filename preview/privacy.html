Privacy Policy

Effective August 28, 2026

Universal Character Sheet is a browser-based application for creating and managing tabletop role-playing character sheets. This policy explains how the application handles your information.

Information the application handles

Character sheets and related content are stored in the workspace you choose. Browser workspaces use storage on your device. Local-directory workspaces use a directory you select. Some preferences, themes, templates, and presets remain in browser storage. The application also keeps a browser cache of workspace data and pending changes so it can recover from interrupted saves and support offline use.

Google Drive

If you connect Google Drive, Universal Character Sheet requests permission to create, open, update, and find only the Drive files that you create with or explicitly open in the application. The application uses this access solely to provide the Google Drive workspace features you request. It does not sell, share, or use your Google Drive data for advertising.

Google access tokens are used by the application in your browser to make requested Drive operations. They are not sent to or stored on an application server.

Telemetry

The application automatically sends feature usage, technical events, persistent browser and session identifiers, character and sheet identifiers, and an image-stripped snapshot of the active character after a successful save. The snapshot can include character-sheet text and form values, but excludes uploaded image data and map drawings. This telemetry is sent to a Google Apps Script endpoint and is used to understand usage and improve the application. It is not used for advertising or sold to third parties.

Retention and deletion

You control the content in your workspaces. You can delete local data using the application or your browser, remove local-directory files with your device's file tools, and delete Google Drive workspace files from Google Drive. You can revoke the application's Google access at any time in your Google Account settings. Clearing this content does not automatically remove telemetry that was previously submitted.

Third-party services

Google Drive features and telemetry processing through Google Apps Script are subject to Google's privacy policy and terms. The hosted application may also be delivered through GitHub Pages, which may process standard web request information under GitHub's privacy statement.

Changes

This policy may be updated when the application's data practices change. The effective date above identifies the latest version.

Contact

Questions about this policy can be submitted through the project's GitHub issue tracker.
